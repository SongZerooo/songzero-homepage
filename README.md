# Song Zero Homepage

这是宋泽荣的个人主页项目，使用原生 HTML、CSS 和 JavaScript 编写，不依赖复杂的前端框架。项目主要分成两块：一个是展示个人经历的主页，另一个是可以读取主页内容并导出自定义简历的简历生成器。

## 一、个人主页

个人主页主要用来集中展示个人信息和经历，内容包括：

- 个人简介和联系方式
- 教育经历
- 实习经历
- 项目经历
- 科研经历
- 学生职务
- 获奖情况
- 职业技能

页面支持中英文切换和浅色、深色主题切换，整体采用比较简洁的个人主页风格。主页上的经历内容直接写在 `index.html` 中，后续修改个人信息时可以直接编辑对应部分。

## 二、自定义简历导出

点击主页顶部的“生成简历”后，会进入独立的简历生成页面。这个页面会自动读取主页中的个人信息、教育经历、实习经历、项目经历、科研经历和获奖情况，不需要再重复填写一遍。

简历生成页面支持：

- 单独填写一份新的自我评价
- 调整正文字号和标题字号
- 调整页边距、行间距和段间距
- 调整右上角证件照大小
- 选择是否加粗标题
- 实时预览 A4 页面
- 内容较多时自动生成多页简历
- 直接导出 PDF

教育经历和获奖经历会根据主页中的结构自动整理，例如教育经历会显示学校、专业、学历、GPA、排名和时间；获奖经历会将奖项名称放在左侧，时间和等级放在右侧。

简历生成页面是独立文件 [resume-generator.html](resume-generator.html)，主页只保留入口。证件照使用 `assets/img/蓝底证件照.jpg`。
